# 🍽️ OmniDine AI — Smart SaaS Restaurant Operating System

> **VibeAthon 6.0 Hackathon Submission**  
> *A Next-Gen 4-Role Interconnected Platform for Dining Automation, Kitchen Line KDS, & Real-Time POS Analytics.*

---

## 📌 Project Overview

**OmniDine AI** is a modern, ultra-sleek, 100% Pure Veg SaaS platform built to seamlessly connect all four stakeholders of a restaurant in real time:

1. **📱 Customer Dining View**: QR Menu browsing, dietary spice customization, Indian Thali platters, live order progress tracking, waiter chat, and instant UPI/QR payments.
2. **🔔 Waitstaff Floor View**: Real-time table floorplan, service call alerts, order acknowledgement, and waiter walkie-talkie chat.
3. **👨‍🍳 Kitchen Chef KDS View**: Real-time kitchen ticket stream with prep timers, line stage bumping (`In Prep` ➔ `Ready`), and dish availability toggles.
4. **💼 Manager Admin Dashboard**: Live sales revenue analytics, floor occupancy %, low-stock inventory alerts, and staff incident reporting.

---

## 🚀 Key Features

- **⚡ Real-Time 4-Role Interconnectivity**: Order actions flow live across Customer, Waiter, Kitchen KDS, and Manager Admin.
- **🌱 100% Pure Veg Gourmet Menu**: Authentic Indian dishes (*Paneer Butter Masala*, *Dal Makhani Royale*, *Hyderabadi Dum Biryani*, *Amritsari Chole Kulcha*, *Shahi Thalis*, *Unlimited Buffets*).
- **📱 Instant UPI & Digital Pay**: Scannable UPI QR codes (`GPay`, `PhonePe`, `Paytm`), card checkout, and downloadable PDF receipts.
- **⚙️ Custom Restaurant Onboarding**: Set custom restaurant name, logo image file/emoji, and local currency symbol (`₹ INR`, `$ USD`).
- **🛡️ Rock-Solid Architecture**: Built with React, Tailwind CSS, Vite, and Error Boundary safety.
